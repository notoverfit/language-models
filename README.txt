this project is just me struggling through understanding the problem of generating sequences of words. i don't jump right into transformers because that isn't an honest
attempt at learning how this all came to be. for years, researchers grappled with simpler methods until the transformer breakthrough was made.

each folder is divided into a major "branch" of language model research. contained within is a readme which goes through the very basic
ideas of the model/approach, as well as jupyter notebooks that implement them.

i hope this repository is somewhat instructive for someone who is also interested in language models and how they came to be. i suggest you explore the repo
in the following order:
1. n_gram
2. lstm (rnn)
3. transformer
